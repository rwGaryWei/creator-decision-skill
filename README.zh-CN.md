# Creator Decision · 创作决策助手

**帮助 AI 创作者判断下一步值得投入什么、作品该怎样改、哪些假设要先验证。**

这是一个可复用 Skill，覆盖网页与工具、视频、短剧和游戏。可以从一个想法开始，也可以带来已有作品或收到的反馈。目标是给出有依据的判断和具体改进方法，保留你真正想表达或实现的东西。

**当前版本：0.1.0-alpha。** 已实现 Skill 指令、领域指南和本地辅助工具。示例是虚构材料，用于展示预期流程；尚无独立模型对照或真实创作者试用结果。许可证仍待仓库所有者选择，详情见[许可状态](docs/licensing.md)。

## 它如何帮助你

例如，你想用 AI 制作上百个游戏角色。助手会追问真正影响决定的问题：玩家是否需要这么多角色？几个角色能否形成不同且有后果的关系？应当优先增加内容、加深互动，还是做一次小范围试玩？它应解释判断依据、改动代价，以及什么新信息会改变建议。

有时合理结论是继续甚至扩大投入。也可能是调整、缩小、验证或暂停。创作表达、娱乐、学习、作品集和商业价值都是合法目标，不会默认把每个人都变成创业者，也不以批评数量衡量质量。

## 使用方法

1. 下载或克隆此仓库。
2. 把完整的 `skills/creator-decision` 文件夹复制到你的项目 `.agents/skills/` 中。
3. 在 Codex 打开该项目，明确调用：

```text
请用 $creator-decision 帮我判断这个 AI 短剧想法。
我的目标是做一部克制、安静的亲情短剧，用作作品集。
目前只有大纲，我能投入两个周末，还没有真实观众反馈。
我希望保留安静的风格。请帮我决定先改哪里、先验证什么。
```

可选安装工具（Python 3.10+）：

```sh
python scripts/install.py --project "你的项目绝对路径"
```

工具不会覆盖已有 Skill。宿主识别及媒体能力的实测范围见[安装说明](docs/quickstart.md)。没有 Skill 功能的助手可以手动读取主文件和相关指南；这不等于已经验证了原生兼容。辅助工具不需要模型 API 密钥；对话使用你选择的 AI 助手，其订阅与费用由该服务决定。

## 输出内容

- 一张简短决策卡：建议、影响的投入、值得保留的内容。
- 支持与反对理由，区分事实、观察、推断和未知。
- 具体改法与代价，不给没有依据的成功概率。
- 一个可执行的验证任务，以及改变建议的条件。
- 新证据出现后的复盘，保留旧版本和你的决定。

网页看任务与使用成本；视频看观看承诺和回报；短剧看人物、选择与因果；游戏看循环、选择和反馈。AI 的生成、挑选、返工、一致性与维护成本都需考虑，但“用了 AI”本身不是好坏结论。

它不能预测销量、保证爆款、认证版权或原创性，也不能用模拟用户替代真实受众。未观看的视频、未听到的音频、未实际操作的产品，会明确写出观察限制。

## 可核查的工程与研究

可选 Python 工具能检查报告结构与引用原文、保存版本、记录你明确说出的接受／修改／拒绝／暂缓。它们不联网、不调用模型、不采集遥测；引用原文匹配不等于观点正确，记录“人工确认”也不是身份认证。

仓库提供 12 个开发案例、12 个独立项目的试跑案例、24 个待审查的正式测试候选案例及实验工具。所有案例是虚构文本，不是假装采集的真实反馈。实际完成情况以[验证记录](docs/validation.md)为准。

欢迎提交可复现的问题和更好的领域判断方法。不要上传私密对话或未经许可的完整作品。GitHub 星标可以表达关注；是否真的帮助创作者做出更好的决定，仍需要试用与研究来检验。
