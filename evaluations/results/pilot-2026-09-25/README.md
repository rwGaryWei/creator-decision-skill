# Exploratory pilot: raw outputs

36 actual isolated subagent responses over 12 fictional projects. No independent human scores or effectiveness finding.

The host does not expose exact deployment, sampling controls, token costs or model timings. Method instructions were loaded from job files. All conditions share the host system context. This is an exploratory host-level pilot, not a tightly controlled API benchmark.

The method-masked review packet is provided separately. Raw responses and labels are public, so masking is not guaranteed; reviewers must disclose whether they consulted them. The mapping is kept outside this repository.
