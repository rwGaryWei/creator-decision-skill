# Changelog

## 0.1.0-alpha · implementation prepared 2026-09-25

- Four-domain skill for idea review, prototype diagnosis and feedback reassessment.
- Decision, experiment and reassessment templates with creative-goal and observation boundaries.
- Optional offline Python report validation, rendering, snapshots, decision journal and structural comparison.
- Project-local installer that refuses overwriting an existing skill.
- Twelve authored demonstrations, twelve pilot scenarios and twenty-four draft formal scenarios.
- Evaluation manifest generation, run-record import, masked review packets and descriptive paired analysis.
- Bilingual entry documentation, development/maintenance guidance and a 64-task progress ledger.

This is an alpha implementation, not a validated v1. Model comparisons, independent reviews, real-creator usefulness, license selection and platform-specific compatibility checks remain open where recorded in the ledger.
