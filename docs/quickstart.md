# First use

Start with a real decision small enough to act on. You do not need a business plan, revenue goal, finished work, or a scorecard.

Provide what you know: what you want to create, why it matters to you, the current decision, what exists, available time/resources, and what you want to preserve. Unknowns are allowed. The skill should ask only questions that could change its advice, then give useful conditional guidance.

Example: “Review my AI-assisted game idea. I want a gentle relationship game, have two weekends, and only a written outline. Keep the quiet tone. Should I add more characters or prototype the first relationship?”

## Installation

For Codex, place the **whole** `creator-decision` folder from `skills/` inside your chosen project's `.agents/skills/`. The result is `.agents/skills/creator-decision/SKILL.md` plus its references, assets and optional scripts. Open or refresh a task in that project and invoke `$creator-decision` explicitly. See the [official skill documentation](https://learn.chatgpt.com/docs/build-skills) and [Agent Skills specification](https://agentskills.io/specification).

The installer does only this copy:

```sh
python scripts/install.py --project "/absolute/path/to/existing/project"
```

For Windows the argument can be a quoted Windows path. If `python` is unavailable, copy the folder manually; conversation use does not require Python. Do not copy only SKILL.md and omit its linked references. Existing installations are not overwritten. To update, compare your local changes, back up the old folder, then deliberately replace it yourself. To uninstall, remove only that installed skill folder after preserving customizations and reports.

**Verified locally:** folder installation into a temporary project and executing the installed Python helper, on Windows with Python 3.12. **Target:** Python 3.10+ for helpers. The CI matrix is configured for Windows/Linux and Python 3.10/3.12; configured is not the same as a completed run. Automatic host discovery, other assistants, macOS and native multimedia use are not yet certified by this release.

If the host does not discover it, verify the project and folder structure, start a fresh task, and explicitly supply the SKILL.md plus the relevant domain reference. Report the assistant/version and exact symptom in a sanitized issue. Do not infer compatibility from the shared Markdown format alone.

## Three entry points

| Entry | Provide | Useful output |
|---|---|---|
| Idea | Promise, intended audience/experience, goal, constraints | Decisive assumption, alternatives, cheapest informative test |
| Prototype | Exact version and accessible artifact | Located experience problem or strength, concrete revision, test |
| Feedback | Previous report, new feedback, collection context | Which assumption changed, updated advice, preserved earlier version |

A script is not a finished video; a screenshot is not an operated tool; a footage description is not a playtest. If the assistant cannot access something, a bounded text review is still useful, but it must say what remains unobserved.

## Privacy and saving

You can stay entirely in the conversation. If you request a saved report, use a private directory; verify source sharing rights before publishing excerpts. Only record accept/modify/reject/defer when you actually choose one. A report generated by the assistant is not your approval.

Use [the decision card](../skills/creator-decision/assets/decision-card.md), [experiment sheet](../skills/creator-decision/assets/experiment.md), or [reassessment sheet](../skills/creator-decision/assets/reassessment.md) without any scripts. Optional [tools](../skills/creator-decision/references/tools.md) provide structured checks and version preservation.

## If the response is unhelpful

Ask for a concrete change to one decision: “Which observation would change this recommendation?”, “What creative goal did this preserve?”, “Give me one alternative with a different tradeoff”, or “Which claim is unverified?” Report the failure rather than treating a confident tone as evidence. An assistant's long report is not automatically a useful one.
