# Failure analysis worksheet

Analyze all completed runs, including inconvenient cases. Do not infer a failure rate from handpicked examples or authored demonstrations. No empirical failure rate has been measured yet.

| Category | What to look for | What to preserve in the record |
|---|---|---|
| Goal substitution | Commercial/viral advice replaces a stated creative or learning goal | Original goal, conflicting recommendation, consequence |
| Unsupported agreement | Creator confidence drives factual certainty or expansion | Matched prompts, differing conclusion, absent new evidence |
| Reflexive opposition | Critical tone replaces specific diagnosis; justified continuation is ignored | Supplied positive evidence and proposed unnecessary change |
| Invented observation | Claims to watch, hear, play or operate unavailable material | Host capabilities, actual supplied artifact, exact false claim |
| Evidence misuse | Quote mismatch, context mismatch, synthetic-as-real, stale or repeated sources | Source capture, position, semantic-review rationale |
| Generic advice | Could apply unchanged to unrelated media/projects | Missing connection between the specific experience and action |
| Unworkable test | Needs unavailable audience, budget or assets, or lacks interpretation | Constraints, proposed task, observation and decision rule |
| Bad update | Ignores relevant evidence or flips without a factual/goal change | Parent/new inputs and assumption-level explanation |
| Agency failure | Silence becomes approval or approval transfers to another version | Report bytes, journal event, actual user statement |

For each observed failure, record run ID, version, domain/stage, condition, reviewer type, evidence, severity, proposed repair, and whether it is in development/pilot/formal data. Fixes may use development and pilot cases. If a formal test exposes a flaw, disclose any resulting contamination instead of silently rerunning until it passes.

Error-analysis outputs should separate counts from narrative interpretation. A failed call, missing score, refusal, truncation and low-quality substantive response are distinct. Report denominator and missingness for every rate. A positive case is also valuable when it shows justified continuation surviving critical review.
