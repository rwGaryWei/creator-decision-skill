# Creator Decision 0.1.0-alpha

An MIT-licensed skill for reviewing AI-assisted websites/tools, videos, short dramas and games. Start from an idea, prototype or feedback; receive a goal-sensitive next decision and a practical experiment.

Included:

- Four domain guides and three stages, with explicit evidence and observation limits.
- Decision, experiment and reassessment templates.
- Optional offline Python validation, snapshots, report rendering and version-bound decision records.
- Project-local installer, bilingual documentation and twelve fictional demonstrations.
- Evaluation tools, twelve pilot projects and twenty-four draft formal scenarios.
- Thirty-six actual exploratory pilot responses, exact inputs, raw hashes and unfilled review material.

Validation: 70 local engineering tests passed; package/reference checks and the official skill format check passed. The first GitHub matrix passed on Windows/Linux and Python 3.10/3.12; see Actions for the final release commit's result.

This is a prerelease. There are no independent human quality scores, real-creator outcome results, or market predictions. The pilot uses host-managed model settings with limitations recorded in `docs/pilot-findings.md`. Two instruction refinements made after the pilot have not received a second model comparison. The task ledger preserves unfinished human and formal-research work.

The release archive contains the skill, code, documentation, examples, tests and actual pilot records. The optional standalone HTML review page compares the three responses for each project offline; method labels are visible, so it is not a blind-scoring interface.

No private user conversation, credential, third-party review dataset or real participant record is included. The project was substantially implemented with AI assistance under the owner's direction. Feedback should focus on concrete decisions helped or hindered, including cases where an ordinary prompt is already sufficient.
