# Portfolio and demonstration kit

## Accurate project description

Creator Decision is an AI skill and offline Python toolkit for reviewing AI-assisted websites, videos, short dramas and games. It combines goal-sensitive domain guidance, traceable evidence, practical experiments and version-bound human decisions. The current alpha includes authored examples and an evaluation harness; effectiveness remains unmeasured. A 36-response exploratory pilot is preserved with explicit host limitations; it has no independent human quality scores.

The project owner originated the problem and product direction and reviews the implementation. AI assistance generated substantial instructions, code, documentation and test materials. Human review, independent evaluation and substantive understanding should be described according to what actually happens, not assumed from repository ownership.

## Five-minute demonstration

1. Explain the problem: easy content production does not establish whether the experience is useful or worth expanding.
2. Open one fictional example. Identify the creative goal, one unknown, the recommendation and the proposed observation that would change it.
3. Validate its JSON and render a new Markdown card. Explain that a literal quote match does not prove semantic support.
4. Save it in a temporary private store. Show that the status is pending. Describe how an explicit decision would bind to the report's exact bytes; do not manufacture a real approval for a demo.
5. Show the separate parent/child report logic in tests and the evaluation manifest generator. State that generated jobs are not completed experiments.

## Questions the owner should be able to answer

- Why is a recommendation separate from a human decision?
- Why is “continue” a valid response and not a failure to be critical?
- What cannot be inferred from a script, screenshot, footage or synthetic comment?
- Why do 432 responses still represent only 24 project scenarios?
- What does the strong B1 baseline control for?
- What can a local hash chain detect, and what can it not authenticate?
- Which failure did you personally reproduce, and what did you change?
- What did the AI implement, and what did you independently review?

Do not claim model-effect improvements, research findings, users, stars, business outcomes or personal implementation effort that have not been measured. This document prepares an interview; it does not demonstrate that the owner has already mastered the material.
