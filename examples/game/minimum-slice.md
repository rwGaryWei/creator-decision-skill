# 最小版本设计示范：安静的园艺解谜

这是为作者内部审查编写的虚构示范，不是模型对照实验、实际试玩结果或已经完成的游戏。依据是现有园艺开发案例中的播种、浇水、等待、收获循环，用水预览、安静节奏与一周作品集目标。下面的数量、规则和界面均为新设计建议，尚未获得创作者接受；不声称这是最优规模或已验证的一周工期。

**建议：先做一屏、一关的完整种植循环。** 保留安静节奏和清楚的行动后果，先验证玩家是否看得懂用水与收获的关系。

**具体设计：** 屏幕放三个花盆、一种种子和一壶共三单位的水。三个花盆的土壤分别标注需要两、一、两单位水；本关目标是收获两盆花。玩家选择花盆播种，浇水前看到本次消耗及剩余水量，确认后扣水。玩家主动点击“等待”让已浇足水的花成熟，再逐盆收获。选择中间花盆与任意一侧即可完成；选择两侧会发现水不足。这个单关只用于展示选择与资源反馈，解谜深度尚未验证。

**保留 / 暂不做：** 保留用水预览、成熟变化、收获反馈与撤销；暂不做商店、任务链、植物图鉴、多关卡和账号。用色块和文字先跑通，再判断是否值得投入生成美术及其一致性修正。

**异常与完成边界：** 水不足时明确提示原因且不扣水；撤销最近一次操作时恢复相应状态和水量；一键重开恢复初始局面。两盆花被收获时显示完成。普通操作、缺水、撤销和重开均与预览一致后，这一版本才达到内部演示条件；它还不能证明玩家觉得有趣或市场认可。

**今天先做：** 用纸面状态表写清一次成功路径和一次选错路径，发现矛盾就改规则；接着实现花盆点击、用水预览和状态变化的无美术单屏。没有可运行版本时，只报告规则检查结果。

如果作者原设想已有不同的种植规则，应优先缩减那些规则，而不是直接覆盖为本示范。
